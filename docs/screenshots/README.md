# Screenshots Archive

This directory stores visual captures of the AeroPulse platform screens and modules for design reviews, AI critique, and before/after comparisons.

Automated screenshot runs are generated using:
```bash
python scripts/tasks.py screenshots
```

Captures are stored in timestamped subdirectories (`docs/screenshots/YYYY-MM-DD-HHMM/`) with a corresponding `manifest.txt`. These generated directories are excluded from Git version control.
